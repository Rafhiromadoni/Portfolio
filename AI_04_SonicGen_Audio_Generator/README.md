# 🎵 SonicGen: AI Audio Generator (Deployment Only)
*(Ganti judul jika ini VisualQNA)*

Berbeda dengan proyek lain di repositori ini yang berawal dari eksperimen di Google Colab, proyek ini adalah demonstrasi **Direct Deployment** untuk model Generative AI / Multimodal.

🚀 **[[KLIK DI SINI UNTUK MENCOBA APLIKASI SECARA LIVE] (Masukkan Link Hugging Face)](https://huggingface.co/spaces/rafhiromadoni/SonicGen)**

## 📌 Deskripsi Proyek
Proyek ini mengimplementasikan model *pre-trained* berbasis Transformer melalui Hugging Face `pipeline`. Tujuannya adalah membangun aplikasi *web-based* yang dapat menerima input teks (prompt) dan menghasilkan output berupa audio secara *real-time*.

## 📂 Struktur Folder
* `app.py`: Skrip utama Python yang berisi logika pemuatan model AI dan antarmuka web interaktif menggunakan Gradio.
* `requirements.txt`: Daftar dependensi server untuk menjalankan aplikasi.

## 💡 Tech Stack
* Python, Gradio, Hugging Face Transformers, PyTorch.
